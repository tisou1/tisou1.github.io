本文是一篇技术随笔，分享我日常写 Git 提交信息的习惯。

为什么要规范提交信息

提交信息是给未来的自己和协作者看的。清晰的历史记录能让你：

  • git log --oneline 一眼扫出变更脉络
  • git bisect 定位问题时更快
  • 自动生成 changelog

Conventional Commits 约定

最常用的格式是 type(scope): subject：

常用 type：

type含义例子
feat新功能增加搜索框
fix修复 bug修复深色模式闪烁
docs文档补充注释
refactor重构提取公共函数
perf性能优化缓存计算结果
test测试补充单测
chore杂项升级依赖
